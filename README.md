

**fain** — автономный новостной поток об искусственном интеллекте без визуального шума, рекламы и кликбейта. Только проверенные релизы, исследования и важные события индустрии в строгом черно-белом терминальном интерфейсе.

---

### // концепция и управление

Лента работает по принципу **Zero-Inbox** — вы видите только то, что еще не читали:

* **Клик по заголовку** — плавно раскрывает блок `// ии-анализ` с оценкой влияния новости на рынок, разработчиков и обычных пользователей.
* **Клик по тексту описания** — отмечает новость прочитанной и навсегда скрывает её с терминальной анимацией схлопывания.
* **Локальная память (`localStorage`)** — прочитанные карточки не возвращаются после перезагрузки страницы, а свежие записи автоматически подтягиваются из облака и группируются по меткам: `сегодня`, `вчера`, `на этой неделе`, `в этом месяце`.
* **Автоочистка** — новости старше 30 дней автоматически удаляются как на стороне воркера, так и в кэше браузера (лимит хранения — 50 актуальных записей).

### // архитектура и конвейер (5 ключей)

Каждый час по крон-триггеру (`0 * * * *`) Cloudflare Worker опрашивает **13 профильных RSS/Atom-источников** и пропускает свежие материалы через каскад из 5 независимых задач Gemini с автоматической ротацией моделей (`Round-Robin` + `Fallback`):

```text
 [ 13 RSS / Atom лент ]
           │
           ▼
   ┌───────────────┐
   │ 0. Парсер XML │ ──► Отсев записей старше 30 дней и проверка URL по базе KV
   └───────┬───────┘
           ▼
   ┌───────────────┐
   │   КЛЮЧ №1     │ ──► Фильтр значимости: отбор прорывных релизов и исследований
   └───────┬───────┘
           ▼
   ┌───────────────┐
   │   КЛЮЧ №2     │ ──► Семантический дедупликатор: сверка со смыслом новостей за месяц
   └───────┬───────┘
           ▼
   ┌───────────────┐
   │   КЛЮЧ №3     │ ──► Техно-редактор: лаконичный заголовок и суть в 2–3 предложениях
   └───────┬───────┘
           ▼
   ┌───────────────┐
   │   КЛЮЧ №4     │ ──► Классификатор: присвоение тега (#релиз, #анонс, #исследование)
   └───────┬───────┘
           ▼
   ┌───────────────┐
   │   КЛЮЧ №5     │ ──► ИИ-аналитик: разбор последствий, плюсов и скрытых камней
   └───────┬───────┘
           ▼
 [ Cloudflare KV (FAIN_KV) ] ──► Отдача JSON на фронтенд (GitHub Pages)
```
